# Blocks — Privacy Policy

The privacy policy for the Android game **Blocks** (`com.mastouri.blocks`), published by Mastouri.

Live at **<https://mohamedmastouri2000-boop.github.io/blocks-privacy/>**, which is the URL given to
the Google Play Console.

The policy in one line: Blocks collects nothing. It requests no Android permissions and has no
internet permission, so it cannot transmit anything. Your best score and your game in progress are
saved only in the app's private storage on your own device.

This repository is public solely so GitHub Pages can serve the page. The game's source lives
elsewhere.
